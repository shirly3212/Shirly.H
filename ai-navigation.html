AI Navigation
Simulation

A concept exploring how AI might reshape spatial navigation — future-facing interface thinking rooted in real interaction principles.

RoleConcept Designer
FocusFuture Technology
FormatInteractive Simulation

Project Overview

Designing for a system that adapts to you.

Most navigation interfaces are built around a fixed map. This concept asked a different question: what does it look like when the interface itself reasons about the route, not just displays it?

My Role

Concept & Interface Design

  • Speculative concept development
  • Interaction and interface design
  • AI behavior scripting for the simulation
  • Visual system for adaptive states

Creative Process

Prototyping a future behavior.

Provocation→ Concept Sketching→ Interaction Model→ Prototype→ Simulation

Reflection

Concept work as a design muscle.

Projects without a client brief are where I test ideas I can't yet justify commercially — this one shaped how I think about adaptive interfaces on every project since.
