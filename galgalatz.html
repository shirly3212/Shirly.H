03 · UI/UX Experience

Galgalatz

Structuring a listening experience around clarity, pace, and everyday use — product thinking applied to a very familiar habit.

RoleUI/UX Designer
FocusProduct Design
FormatDigital Platform

Project Overview

Designing for a habit, not a session.

Galgalatz is used in short, frequent bursts rather than long dedicated sessions — the design had to respect that rhythm, prioritizing speed and legibility over ornamentation.

My Role

UI/UX Design

  • Information architecture
  • Interface design and design system components
  • User flow mapping
  • Usability-driven iteration

Creative Process

From flows to a working interface.

User Research→ Flow Mapping→ Wireframes→ UI Design→ Usability Pass→ Final Interface

Reflection

Restraint as a UX decision.

The strongest interface choices here were subtractive — fewer taps, fewer states, fewer decisions asked of the listener at any one moment.
